## 薪資前端「點選單變儀表板」==> 已解決
- 症狀：admin 登入後點 sidebar「薪資單/薪資結構」卻顯示儀表板。
- 根因：**vite dev server 是加入薪資路由之前啟動的舊實例**。Vue Router 的 HMR 只重跑 `router/index.ts` 產生新 router 實例，不會重掛進 `app.use(router)`（`main.ts`）；執行中的 app 一直用「舊路由表」，新路由 `/payroll/payrolls`、`/payroll/salaries` 不存在 → 命中 catch-all `/:pathMatch(.*)*` → redirect `/` → 儀表板。側欄選單來自權限（與路由表無關）所以仍顯示。
- 修法：重啟 vite dev server（新實例拿目前 source 建路由表）＋瀏覽器重新載入。
- 驗證：無頭 Chrome + CDP + 注入 admin token，直開 `/payroll/payrolls`、`/payroll/salaries`、`/attendance/my` 全部正常渲染（薪資 4 筆、薪資結構 5 員工、出勤）。
- 教訓：**新增/修改路由後務必重啟 vite；只要「sidebar 有新選單但點下去是儀表板」就是 router 表過舊**。腳本在 `%TEMP%\opencode\verify-hr.mjs`（可用於日後前端冒煙測試）。
